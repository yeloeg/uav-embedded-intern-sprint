# 05_px4 · PX4 二次开发

**时间**：W10

## 每日任务

- W10D1 搭建 PX4 开发环境（Ubuntu + Gazebo + jMAVSim）
- W10D2 理解 PX4 架构：NuttX RTOS、uORB 消息总线、模块化设计
- W10D3 编写一个 PX4 自定义模块（自定义传感器驱动或简单控制模块）
- W10D4 SITL 仿真运行：`make px4_sitl gz_x500` 启动 PX4 + Gazebo 联合仿真
- W10D5 在仿真中验证自定义模块功能
- W10D6 对比 PX4 与 ArduPilot 架构差异（NuttX 微内核模块化 vs ChibiOS 单体式面向对象）
- W10D7 Boss：GitHub 完整项目 + 简历弹药库 ≥ 5 条

## 产出物

- `custom_module/`：自定义模块源码
- `px4_vs_ardupilot.md`：架构对比文档
- 录屏 ≥ 1 段 → 记入 `/简历弹药库.md`
