# 01_c · C 语言内功

**时间**：W1 ｜ **每天 2 小时，周末 4 小时**

## 本周目标

把 C 语言从「会用」提到「能讲清内存和编译行为」，并且全部用飞控场景包装。

## 每日任务

- W1D1 手写 `memcpy` / `strcpy` / `swap`，解释 `volatile` / `static` / `const`
- W1D2 内存布局、位操作宏、环形缓冲区
- W1D3 函数指针 + 命令表，实现命令行解析
- W1D4 编译四阶段，观察 `.elf` / `.map`
- W1D5 小项目：串口命令行控制 LED
- W1D6 面试题：C 语言 20 题（结合飞控场景，如「为什么飞控中 `volatile` 修饰传感器数据」）
- W1D7 Boss：Git 提交 + 复盘

## 产出物

- `w1d1/` ~ `w1d5/`：每天的代码，按子目录分
- `notes.md`：本周踩坑与结论
- 证据：`/故障博物馆.md`（如遇故障）、`/波形证据.md`（串口波形）、`/飞控面试题库.md`（20 题）

## 本周通过标准

能口头解释：一段带 `volatile` 的传感器读取代码，为什么不能把 `volatile` 去掉。
