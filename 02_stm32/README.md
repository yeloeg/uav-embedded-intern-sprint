# 02_stm32 · STM32 外设（飞控视角）

**时间**：W2

## 本周目标

外设不是"点亮 LED"，而是"飞控上的哪个部件靠它工作"。

## 每日任务

- W2D1 GPIO + 外部中断按键消抖
- W2D2 定时器 PWM 输出 —— **飞控视角：电机 PWM 信号生成，理解 1000 - 2000us 脉宽与 ESC 控制**
- W2D3 UART DMA + 空闲中断 —— **飞控视角：接收遥控器 SBUS / CRSF 信号**
- W2D4 I2C 驱动 MPU6050 —— **飞控核心传感器：六轴 IMU**，抓 SCL / SDA 波形
- W2D5 SPI 驱动 Flash，对比 I2C / SPI 选型
- W2D6 小项目：MPU6050 数据采集 + 串口上报
- W2D7 Boss：故障博物馆第 1 篇 —— I2C 偶发失败定位

## 产出物

- `w2d1/` ~ `w2d6/`：每天的代码
- 波形截图：PWM 脉宽、I2C 时序、SBUS 帧 → 记入 `/波形证据.md`
- `/故障博物馆.md` 第 1 篇

## 本周通过标准

能用逻辑分析仪定位通信问题，能解释飞控中传感器选型的理由。
