# uav-embedded-intern-sprint

无人机飞控嵌入式软件实习生 · 12 周冲刺打卡仓库

## 目标岗位

**无人机飞控嵌入式软件实习生**（深圳 / 低空经济方向优先）

## 主项目

**基于 STM32 + FreeRTOS 的四旋翼飞控固件**

技术栈：STM32F405 / FreeRTOS / MPU6000 / MAVLink / SBUS / 串级 PID

产出目标：

- 5 任务飞控架构（姿态估计 1kHz / 控制 1kHz / 通信 50Hz / 日志 10Hz / 监控 1Hz）
- 四元数姿态解算 + 互补滤波，静态姿态误差 < 1°
- 串级 PID（角度环 + 角速度环），有阶跃响应测试数据
- MAVLink 接入 QGroundControl，遥测 50Hz，丢包率 < 0.1%

## 辅项目

**PX4 自定义模块开发 + SITL 仿真验证**

技术栈：PX4 / NuttX / uORB / Gazebo SITL

产出目标：

- 基于 PX4 框架开发自定义控制模块（uORB 订阅 + 发布）
- Gazebo SITL 中完成定点悬停与航点飞行测试，留录屏
- 输出 PX4（NuttX 微内核）与 ArduPilot（ChibiOS）架构对比文档
