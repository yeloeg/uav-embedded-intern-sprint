# 03_rtos · FreeRTOS 攻坚（飞控任务架构视角）

**时间**：W5 - W7

## 目标

所有实验都从「飞控任务」角度做，而不是教科书式跑例程。

## 每日任务

**W5 RTOS 入门**

- W5D1 移植 FreeRTOS，创建飞控典型任务：姿态估计、控制输出、通信
- W5D2 默写任务状态切换图
- W5D3 队列传递 IMU 数据到姿态解算任务
- W5D4 二值信号量做 IMU 中断同步
- W5D5 互斥量保护 I2C 总线共享资源（IMU + 气压计）
- W5D6 小项目：3 任务飞控框架（采集 / 解算 / 输出）
- W5D7 Boss：面试题 —— 飞控中队列 vs 信号量 vs 互斥量

**W6 RTOS 进阶**

- W6D1 事件组 / 任务通知（「IMU 数据就绪」事件）
- W6D2 优先级反转实验（姿态控制任务 vs 低优先级日志任务）
- W6D3 `uxTaskGetStackHighWaterMark()` 栈检测
- W6D4 `heap_4` 内存管理
- W6D5 软件定时器（1kHz 控制周期）
- W6D6 小项目：完整飞控任务框架（采集 / 解算 / 控制 / 通信 / 日志）
- W6D7 Boss：故障博物馆第 3 篇 —— 优先级反转；PendSV 中断作用

**W7 实时性与稳定性**

- W7D1 控制周期抖动测量（替代低功耗方向）
- W7D2 测量控制任务执行时间，确保 1kHz 循环不超时
- W7D3 看门狗 + 任务监控
- W7D4 启动长时间稳定性测试
- W7D5 优化任务优先级和栈大小
- W7D6 量化数据：控制周期抖动、CPU 利用率、栈使用率
- W7D7 Boss：面试题「FreeRTOS 多任务调度与 Linux 进程 / 线程调度的区别」

## 本周通过标准

能画出飞控任务的**优先级 + 周期 + 栈大小**表，并给出每个数字的依据。
