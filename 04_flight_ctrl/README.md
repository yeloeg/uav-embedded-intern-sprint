# 04_flight_ctrl · 通信协议 · 飞控算法 · 飞控固件

**时间**：W3 - W4、W8

这是整条路线最核心的差异化目录 —— 通用嵌入式路线里没有这些东西。

## W3 通信协议深挖（飞控场景化）

- W3D1 I2C / SPI 时序 + 开漏上拉（MPU6050 / DPS310 气压计场景）
- W3D2 CAN 总线基础：仲裁逻辑、显性 / 隐性电平、过滤器配置
- W3D3 UART 帧格式 + 波特率误差，实现 SBUS 协议解析
- W3D4 **MAVLink 协议入门**：消息帧结构、心跳包、常见消息 ID
- W3D5 用 STM32 实现简易 MAVLink 消息收发
- W3D6 小项目：STM32 通过 MAVLink 发送姿态数据到 QGroundControl
- W3D7 Boss：波形证据 ≥ 3 张 + 面试话术「MAVLink 在飞控中的角色」

## W4 飞控算法基础 + 工程化

- W4D1 PID 控制原理：位置式 / 增量式、串级 PID（外环角度 / 内环角速度）
- W4D2 STM32 上实现单轴 PID 控制实验
- W4D3 姿态解算入门：欧拉角 / 四元数，互补滤波融合加速度计 + 陀螺仪
- W4D4 卡尔曼滤波 / EKF 基础概念（MPU6000 以 1kHz 采样，EKF 融合陀螺仪与加速度计）
- W4D5 HardFault 定位 + 看门狗实验
- W4D6 给 MAVLink 通信加 CRC 和重传
- W4D7 Boss：故障博物馆第 2 篇 —— HardFault 定位；飞控面试题 10 道

## W8 飞控固件框架搭建（主项目启动）

- W8D1 需求文档：姿态稳定、遥控接收、MAVLink 遥测
- W8D2 硬件选型：STM32F405 / F411 + MPU6000 + DPS310 + SBUS 接收机
- W8D3 软件分层：HAL → 驱动 → 算法 → 任务 → 通信
- W8D4 飞控任务框架：姿态估计 1kHz、控制 1kHz、通信 50Hz、日志 10Hz
- W8D5 PID 控制器实现：串级 PID（角度环 + 角速度环）
- W8D6 互补滤波 / 四元数姿态解算实现
- W8D7 Boss：README 初版（同步更新根目录 README）

## 通过标准

- W3 - W4 结束：能画出飞控数据流图（IMU → 姿态解算 → PID → PWM 输出）
- W8 结束：能讲清 5 个任务的周期为什么这么定
